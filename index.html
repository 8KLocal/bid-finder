GitHub Pages

Paste a Payment Link from the itsworkplace.com Stripe account into assets/config.js:

stripePaymentLink: "https://buy.stripe.com/…"

On that Payment Link, set the success URL to https://8klocal.github.io/bid-finder/?checkout=success and the cancel URL to https://8klocal.github.io/bid-finder/?checkout=cancel#pricing.

Checkout Sessions

Set STRIPE_SECRET_KEY and STRIPE_PRICE_ID (the price_… for Starter at $29/month) on the API, then run node scripts/dev-server.mjs or deploy the api/ routes. The secret key stays on the server. See the README and .env.example.

You can also set stripePublishableKey and stripeBuyButtonId to show Stripe’s official Buy Button. Do not put a secret key in config.js.
